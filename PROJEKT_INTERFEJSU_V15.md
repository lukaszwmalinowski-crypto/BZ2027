# Studio danych / Śląskie 2027 — v15

Kompletny redesign warstwy wizualnej i układu z zachowaniem wszystkich danych i modułów panelu v12.

## Co zostało przebudowane

- Stała boczna nawigacja rozdziałowa (na mobile: zwarty pasek górny).
- Dwa poziomy nagłówka, duża okładka wydawnicza i pasek wskaźników.
- Sterowanie mapą i analizami przeniesione do niezależnego docka filtrów.
- Mapa jest dominującą wizualizacją, zaś sygnały powiatowe zostały przeniesione do panelu kontekstowego.
- Pięć rozdziałów analitycznych zamiast długiej, anonimowej listy kafelków.
- Zaokrąglone, miękkie kształty, bardziej wyrazista typografia i delikatna kolorystyka fioletu i błękitu.
- Wykresy: nowe tła, siatki, stany przycisków, czytelniejsze metadane, powiązana paleta w trendach.

## Co zachowano

Źródła i dane v12, 36 jednostek, filtry i obsługę mapy, profile zawodów, BAEL, REGON, trendy, historię bezrobocia powiatowego z dotychczasowymi ograniczeniami, raporty PDF/PPTX/XLSX, tryb prezentacji, import BDL/CSV/JSON, dokumentację źródeł. Żadnego logo WUP.

## Ważne

Poprawa wyglądu nie uzupełnia danych. Pełna historia wszystkich powiatów nadal wymaga faktycznego pobrania GUS/BDL. Aby uruchomić GitHub Pages, przesłać zawartość ZIP do katalogu głównego repozytorium.
