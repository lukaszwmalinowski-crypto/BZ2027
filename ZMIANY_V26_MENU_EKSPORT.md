# Obserwatorium Śląskie 2027 – v26

## Poprawione menu Eksportuj
- Rozwijane menu PDF / PowerPoint / Excel pojawia się nad paskiem nawigacji i treścią strony.
- Usunięto obcinanie zawartości przez nagłówek (`overflow: hidden`).
- Zachowano wyraźne przerwy między pozycjami i marginesy.
- Utrzymano zamykanie po kliknięciu poza menu i klawiszem Escape.
- Nie zmieniano danych ani formatu `data/dane.json`, kodu wykresów i generatorów dokumentów.

Aby wdrożyć na GitHub Pages, podmień cały `index.html`. Pozostałe pliki nie uległy zmianie.
