# Uniwersalny eksport „Dane dla AI” — v95

Wybierz dowolny powiat lub województwo, naciśnij „Dane dla AI” i prześlij powstały plik JSON do narzędzia analitycznego. Nie jest to sztywny prompt do prezentacji: dane zawierają opis metodologii, zasady interpretacji, kontekst transformacji, benchmarking 36 jednostek, spis dostępności danych, logikę analizy trendów i scenariuszy.

**Ważne:** Barometr Zawodów jest prognozą jakościową, a nie liczbą wakatów. Historyczne szeregi nieobecne w aplikacji nie są wytwarzane. Ogólnowojewódzkie dane GUS nie są lokalnymi danymi powiatu. Historyczne i krajowe źródła należy weryfikować przy pytaniach o najnowszą sytuację.

Przykładowe zapytania: „Jak zmieniła się sytuacja zawodów medycznych w powiecie?”, „Zaproponuj scenariusze kompetencyjne do 2030”, „Stwórz infografikę o deficytach i demografii”, „Przeanalizuj ryzyka transformacji przemysłu i wskaż źródła niepewności”, „Przygotuj 12-slajdową prezentację z mocnymi wnioskami i źródłami”.

Oficjalne źródło metodologii: https://barometrzawodow.pl/strona/metodologia
